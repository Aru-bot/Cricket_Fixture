# Cricket League Fixture Generator

A simple web app to generate round-robin cricket league fixtures.

## Features

- Generate input fields for team names
- Create a round-robin fixture schedule
- Toggle between light and dark themes
- Theme preference is persisted in local storage

## Usage

1. Open `cricket_league_manager.html` in a browser.
2. Enter the number of teams and click **Generate Team Input Fields**.
3. Enter each team name.
4. Click **Generate Fixtures** to see the match schedule.
5. Use the **Switch to Dark Theme** button to toggle themes.

## Files

- `cricket_league_manager.html` - Main HTML app with embedded CSS and JavaScript
- `README.md` - Project overview and usage instructions

## Notes

- Requires only a modern browser; no backend or build tools needed.
- The theme preference is stored locally in the browser.
